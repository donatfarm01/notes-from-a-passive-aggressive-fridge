One funny passive-aggressive note a smart fridge leaves for its owner,
written by `main.py` to `/output/entry.txt`.

The fridge has kept the owner's leftovers cold for six days. The
leftovers, unlike the owner, have started paying rent. Dry, petty,
specific, and exactly the sort of thing a smug appliance would keep
on its door screen.

## Run

Run `main.py` with Python 3.13. It writes a single line of 1 to 200
characters to `/output/entry.txt`, with no trailing newline, after
checking the note against the bounty gate first.
